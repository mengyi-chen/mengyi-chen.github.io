# mengyi-chen.github.io

Personal academic homepage of Mengyi Chen (Ph.D. student in Mathematics, National University of Singapore).

Live site: https://mengyi-chen.github.io

Built with Jekyll on GitHub Pages, using the [Minimal Light](https://github.com/yaoyao-liu/minimal-light) theme by Yaoyao Liu (MIT License).

## Editing

- Profile and links: `_config.yml`
- About, News, Education, etc.: `index.md`
- Publications: `_data/publications.yml` (thumbnails in `assets/img/pubs/`)
- CV: `assets/files/Mengyi_Chen_CV.pdf`
